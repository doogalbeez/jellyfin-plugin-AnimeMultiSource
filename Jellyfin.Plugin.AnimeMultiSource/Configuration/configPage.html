Sync

A sync fills in shows and movies that have no anime metadata yet, refreshes tags of shows whose last episode arrived, and of recent films added, about a week or 3 months ago, and updates AnimeSchedule.net upcoming episodes. It only touches what needs it, one title at a time, so it stays gentle on the APIs even for very large libraries. Titles with no anime match are only retried by Sync now. Longer intervals mean fewer API calls; upcoming air dates also update whenever a show is refreshed.
Runs a sync right away, including titles that had no anime match before. Progress shows under Dashboard > Scheduled Tasks, and a summary goes to Dashboard > Activity.
Adds the tag "Anime Multi Source" (listed under Tags on the item's page, and usable as a library filter). Turning this off removes the badge on the next sync.
The plugin also writes its own log, AnimeMultiSource_YYYY-MM-DD.log, under Dashboard > Logs (kept 7 days). Debug adds every API call and match decision, for tracking down a wrong or missing match. Jellyfin's main log is not affected.

Title Configuration

Runtime Configuration

Anilist provides duration in minutes. Jikan provides duration as string (e.g., "24 min").

Cast Language

The original cast is the anime's production language (Japanese for Japanese anime). A dub cast, e.g. English, is only added when an episode or movie file has an audio track in that language. Dub roles are labelled, e.g. "Frieren (English dub)".

Movie Configuration

Movies are matched by AniList/MAL/TMDb/IMDb id first (from the item, an NFO, or a .plexmatch in the movie folder). When none of those exist, search AniList for an anime film with the exact same title and release year (±1). Turn this off if the library also holds non-anime films.
